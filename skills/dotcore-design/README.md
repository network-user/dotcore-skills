# DotCore Design

Универсальный UI/UX-скилл для сайтов, мобильных и desktop-приложений. Помогает
спроектировать сценарии, задать оригинальное визуальное направление в эстетике
DotCore, адаптировать его под платформу и проверить доступность интерфейса.

Применяй для новых экранов, дизайн-систем, адаптации существующего продукта,
реализации UI и UX/UI-ревью. Существующие правила проекта и явные референсы
пользователя имеют приоритет над стилем DotCore по умолчанию.

Платформенные рекомендации и визуальные токены: [platforms-and-style.md](references/platforms-and-style.md).
Критерии проверки реализации: [design-review.md](references/design-review.md).

Установка из корня этого репозитория:

```powershell
.\scripts\install.ps1 -Skill dotcore-design
```

```bash
./scripts/install.sh dotcore-design
```
