# Domain - README, AGENTS.md, SKILL.md, docs DotCore

Покрывает человеческую и агентную документацию экосистемы DotCore. Гонять вместе с [professional-pass.md](../professional-pass.md) и [ru-register.md](../ru-register.md). Длинный README или гайд - ещё outline/QUD из [discourse-pass.md](../discourse-pass.md) §1–3.

Канон площадки: скилл `generate-readme` и `docs/ADDING_SKILL.md`. Этот файл не подменяет их workflow - он чинит *слог* внутри уже выбранной структуры.

## Human baseline

Сухой internal doc. Что это, как запустить, какие команды, где правда. Без tagline, без storytelling, без «мы рады представить». Структура формульная (это контейнер, не маркер): header-бейджи, обложка, секции Запуск / Команды / Стек / Архитектура / Лицензия.

`AGENTS.md` - для агента: команды, инварианты, запреты. `SKILL.md` - workflow по шагам, self-check, ссылки одним уровнем. Не путать аудитории.

## AI tells в этом домене

| Маркер | Фикс |
|---|---|
| Marketing-абзац после заголовка, centered hero, `<details>`, emoji | Плоский техдок. Убрать обёртку |
| Каждая секция одной длины, каждая начинается с определения темы | Длина по пользе. Секция без факта - удалить |
| «Проект представляет собой…», «решение позволяет…» | Одно предложение: тип + ключевое решение |
| Fractal summary: анонс → текст → резюме в каждой секции | Сказать один раз |
| Выдуманные команды, флаги, пути, LoC | Только из `scripts/`, CI, кода. Нет факта - TODO или спросить |
| Лицензия «смягчена» или пропущена | Как в репо; в DotCore по умолчанию All Rights Reserved |
| AGENTS.md дублирует README | README - человеку, AGENTS - агенту; ссылка, не копия |
| SKILL.md без триггеров и self-check, зато с эссе о важности | description = что + когда; тело = шаги |

## Правила

1. **Факт раньше формулировки.** Команда, путь, число - из репозитория. Старый README не авторитет.
2. Буллеты вида `**ключ**: значение`. Одно точное предложение лучше трёх с водой.
3. Не перечислять очевидное. Если секция не меняет поведение читателя - её нет.
4. Русский, если проект не целиком на английском. Пакеты и техтермины - как в коде.
5. Не латать разметку README вручную, когда нужен `generate-readme`. Sepia правит черновик или чужой слог; структуру стандарта не ломает.
6. Блок `<!-- audit:start -->…<!-- audit:end -->` и маркеры LoC не «улучшать».
