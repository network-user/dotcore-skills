# Launch Video

Скилл собирает короткий ролик о текущем проекте или переданном сайте: изучает
реальные функции и фирменный стиль, готовит раскадровку, композицию, видео, постер
и подпись для публикации. Результаты сохраняет в `launch-video/`; голос за кадром
выключен, пока его явно не попросят.

## Когда применять

- «Сделай короткое видео о моём проекте»
- «Покажи в ролике, как работает это приложение»
- «Собери launch video / product demo для сайта»

Тон, формат и длительность можно задать обычным текстом или параметрами из
[SKILL.md](SKILL.md).

Для самостоятельных браузерных сцен подходит [html-motion](../html-motion/README.md).
`launch-video` использует похожие принципы анимации внутри полного процесса
подготовки ролика о продукте.

Вдохновение для end-to-end сценария: [latent-spaces/brag](https://github.com/latent-spaces/brag).
Правила и реализация этого скилла написаны для DotCore отдельно.

## Установка

Из корня `dotcore-skills`:

```powershell
.\scripts\install.ps1 -Skill launch-video
```

```bash
./scripts/install.sh launch-video
```

Подробности: [SKILL.md](SKILL.md).
