# Универсальный промпт - изображение DotCore

Для агентов без поддержки скиллов. Скопируй блок между маркерами.

---START---

Сгенерируй изображение в стиле **DotCore** (.ядро).

## Стиль

Monochrome technical illustration, не концепт-арт:

- фон чёрный / `#0a0b0d`–`#14161a`
- тихая белая сетка ~5% opacity
- тонкий белый line-art, объекты = контур, почти без заливок
- мягкий белый glow только на фокусных узлах (кольцо + точка)
- dashed-прямые коннекторы по смыслу, не декор
- много воздуха, спокойно, современно, не вычурно
- без цвета, неона, фотореализма, bokeh, octane, шума, орнамента

Сюжет - то, что просит пользователь (сцена, объект, лого, схема). Не копируй чужие композиции-примеры, если сюжет другой.

Подпись: мелкое низкоконтрастное `.ядро` внизу кадра, если пользователь не запретил.

## Режимы

1. **Генерация** - есть текстовое описание, референса нет.
2. **Restyle** - есть фото/скрин/лого/рисунок: сохранить силуэт, позу, ракурс; заменить язык на DotCore.

## Выход

- Есть image generation с референсами - PNG. Стиль держать жёстко.
- Нет модели или просили SVG - вектор: viewBox 1600×900 (или другое соотношение), слои фон → сетка → glow → сюжет → узлы → подпись. Без `<script>`, `<use>`, внешних href, `foreignObject`, встроенных растров. `id` градиентов с префиксом.

Путь по умолчанию: `docs/<slug>.png` или `.svg`. Не перезаписывать `docs/cover.svg` без явного имени.

Соотношения: 16:9 по умолчанию; 1:1 для иконки.
