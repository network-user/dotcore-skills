# Стиль DotCore (визуальный язык)

Не палитра «тёмная тема вообще», а конкретная эстетика двух канонов в `references/`. Сюжет любой - токены те же.

## Канон

| Файл | Что брать | Что не брать |
|------|-----------|--------------|
| `style-illustration.png` | тонкий белый контур, объекты-схемы, dashed-коннекторы, круги-узлы с точкой, мягкий белый halo | человека за столом, кружку, растение - если это не сюжет запроса |
| `style-brand.png` | квадратная сетка, радиальное свечение за объектом, геометрический знак, жирная гротеск-надпись, пустое поле | слово CURSOR и куб со стрелкой - если это не сюжет запроса |

Итог для зрителя: чертёж / схема на чёрном, не концепт-арт и не UI-шот с эффектами.

## Токены

| Элемент | Значение |
|---------|----------|
| Фон | `#000000` … `#0a0b0d` → `#14161a`, края темнее центра |
| Сетка | тонкие линии `#ffffff`, opacity **0.04–0.06**; квадраты или редкие оси. Видна приглядевшись, не спорит с сюжетом |
| Glow | только белый, radial, opacity **≤ 0.14**. На фокусных узлах / знаке, не на всём кадре |
| Линии | `#f3f3f1` / `#ffffff`, постоянная тонкая толщина, round caps |
| Заливка | почти нет. Допустима точка внутри узла и сплошная буква/знак |
| Вторичный текст | `#a6a7ab` |
| Подпись `.ядро` | `#3a3b40`–`#5a5b60`, 10–14 px на 1600-кадре (или эквивалент), низ, центр или чуть смещён. Контраст низкий |
| Узел | окружность + точка в центре + мягкий halo. 3–7 штук, не рой |
| Коннекторы | прямые dashed, белые, тонкие |

Шрифт локапа: геометрический гротеск (Inter / Arial), weight 700–800, tracking слегка отрицательный. Не декоративные, не моно с засечками как «хакерский» клише.

## Регистры (выбери по запросу, не ограничивайся ими)

- **Сцена** - персонаж/пространство сведены к контуру; если система/агенты/сеть - узлы вокруг фокуса.
- **Локап** - знак + слово, много воздуха, сетка, glow за знаком.
- **Объект** - restyle фото: силуэт предмета/лица контуром, фон заменён на сетку.
- **Схема** - узлы и рёбра как главный сюжет.

UI-мокап (окно, строки «кода», три точки) - только если сюжет про редактор/софт. Не украшение каждого кадра.

Лёгкая изометрия знака допустима (как куб на brand-каноне). Фотореалистичный 3D, стекло, caustics - нет.

## Обязательно

- Monochrome. Один акцент - белое свечение, не цвет.
- Много отрицательного пространства. Кадр спокойный, не вычурный, не «богатый».
- Современный минимализм: мало элементов, выровненные оси, без орнамента.
- Подпись `.ядро`, пока пользователь не отключил.

## Запрещено

- Цвет, градиенты радуги, неон, RGB-glow
- Фотореализм, кожа, ткань, шум сенсора, bokeh, volumetric fog
- Сток-эстетика нейросетей: cinematic lighting, octane, unreal, chrome girl
- Толстые заливки, тени-кляксы, акварель, глитч, vaporwave
- Водяной знак кроме `.ядро`; копирование чьих-то логотипов, если это не сюжет
- Перегруженный UI, мелкий нечитаемый «lorem code» на весь кадр

## Restyle (режим B)

Сохранить: объект, позу, ракурс, узнаваемый силуэт, тип сцены (портрет / продукт / интерьер).

Заменить: цвет → монохром; фототекстуры → контур; задник → тёмная сетка; блики → белые узлы/halo.

Не сохранять чужой художественный стиль (масло, аниме, комикс) - только содержание кадра, язык DotCore.
