# Generate DotCore Image

Отдельный скилл визуала DotCore. **Сюжет любой** (сцена, объект, лого, схема, UI) - стиль один. Обложки README (`docs/cover.svg`) этому скиллу **не принадлежат** - их пишет `generate-readme`.

Главное правило: **сначала raster, если в агенте есть image generation; иначе SVG.** Не имитируй нейросеть ASCII-артом и не подставляй стоковые картинки.

## Когда применять

- «сделай картинку в стиле dotcore / .ядро»
- «нарисуй иллюстрацию …»
- «перерисуй это фото / скрин / лого в dotcore»
- нужен PNG/SVG для docs, статьи, соцсети, презентации - в эстетике репозитория

Не применять: правка `docs/cover.svg` ради README (это `generate-readme`); генерация «просто так», без запроса картинки.

## Режимы

| Режим | Сигнал | Вход |
|-------|--------|------|
| **A. Генерация** | описали сюжет, референса нет | текст + style-референсы скилла |
| **B. Restyle** | прислали файл(ы) / «перерисуй» | любой референс (фото, скрин, лого, рисунок) + style-референсы |

Подпись **`.ядро`**: по умолчанию **да**, максимально незаметно (мелкий muted-серый, низ контраста, низ кадра). Убрать - только если пользователь явно сказал не надо.

## Workflow

### 1. Intent

Зафиксируй (не переспрашивай очевидное):

- режим A или B
- сюжет / что сохранить из референса
- формат: пользователь сказал `svg`/`png` - уважай; иначе raster-first
- соотношение: из запроса, иначе **16:9** (широкая иллюстрация), **1:1** (иконка/аватар)
- путь: явный от пользователя, иначе `docs/<kebab-slug>.png` или `.svg`
- подпись `.ядро`: on, если не отключили

Не перезаписывай `docs/cover.svg` без явного имени файла от пользователя.

### 2. Style lock

Прочитай [style.md](style.md). Канон стиля - два PNG рядом со скиллом:

- [references/style-illustration.png](references/style-illustration.png) - сцена, line-art, узлы
- [references/style-brand.png](references/style-brand.png) - локап, сетка, типографика

Абсолютный путь: каталог этого `SKILL.md` + `references/…`. Сюжет **не** копируй с референсов (человек за столом / слово CURSOR) - только визуальный язык.

### 3. Raster (предпочтительно)

Если в этом агенте есть генерация изображений (в Cursor - инструмент GenerateImage):

1. Собери промпт по [raster.md](raster.md).
2. `reference_image_paths`:
   - **A:** оба style-PNG
   - **B:** файл(ы) пользователя **первыми**, затем оба style-PNG
3. `aspect_ratio` только из набора инструмента: `1:1` `4:3` `3:4` `16:9` `9:16` (ближайшее к запросу).
4. `filename` = basename целевого пути.
5. Один вызов. Если инструмент вернул файл не туда - скопируй/перенеси в целевой путь.
6. Провал или нет инструмента → шаг 4, без повторных «творческих» промптов.

Не вызывай генерацию, если пользователь просил только SVG.

### 4. SVG (fallback или явный запрос)

Пиши SVG текстом по [svg.md](svg.md). Слои: фон → сетка → glow → сюжет line-art → опциональные узлы → подпись. Без `<script>`, `<use>`, внешних href, `foreignObject`, встроенных растров.

### 5. Validate

Self-check ниже. Нарушение стиля (цвет, неон, фотореализм, вычурность) - перегенерируй **один** раз; второй провал - SVG.

## Чего не делать

- цвет, неон, радуга, cinematic bokeh, «octane / unreal engine»
- копировать композицию style-референсов, если сюжет другой
- тяжёлые заливки, шум, текстуры кожи/металла
- перезаписывать README-обложку и бейджи аудита
- секреты, machine-paths, чужие водяные знаки на картинке
- выдавать чужой сток за результат

## Self-check

- [ ] Режим A/B выбран по запросу; restyle сохраняет силуэт/композицию источника
- [ ] Monochrome DotCore: тёмный фон, тихая сетка, тонкие белые линии, glow только на фокусе
- [ ] Нет вычурности: пустое пространство, ровный line-weight, современный спокойный кадр
- [ ] `.ядро` незаметно внизу **или** отсутствует по явной просьбе
- [ ] Файл лежит по заявленному пути; `docs/cover.svg` не тронут без явного запроса
- [ ] Raster был первым, если инструмент доступен; иначе честный SVG
- [ ] SVG: префикс `id`, без script/use/внешних href
