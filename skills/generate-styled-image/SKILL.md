# Generate Styled Image

Иллюстрация в том стиле, который задан сейчас. Стиль DotCore (сетка, line-art, «.ядро») сюда не входит: его делает `generate-dotcore-image`.

## Когда применять

- Пользователь указал файл стиля или вставил канон и просит кадр.
- «В этом стиле», «по канону», «иллюстрация к этому фрагменту».
- Несколько вариантов одного фрагмента.

Не применять, если просят стиль dotcore, «.ядро» или monochrome line-art. Это `generate-dotcore-image`.

## Workflow

### 1. Стиль только из этого запроса

Прочитай файл или текст канона, который пользователь дал сейчас. Нет файла и нет вставленного канона: один раз спроси путь. Не ищи стиль по старым картинкам и не собирай его из памяти о прошлых кадрах.

Канон говорит, что можно менять и чего в кадре нет. Чего в каноне нет, в кадр не добавляй как традицию серии.

Если канон называет одну картинку настроения, её можно передать в генерацию как ощущение света, материала и палитры. Композицию, людей и предметы с неё не копируй.

### 2. Сюжет только из этого фрагмента

Сюжет, шутка и число людей берутся из абзаца, который иллюстрируем. Соседние кадры, прошлые версии и каталоги старых файлов не открывай, пока пользователь сам не назвал конкретный файл.

Несколько вариантов: разные сюжеты этого же фрагмента. Не вариации старого кадра.

Человек появляется, только если он нужен этому фрагменту или этому канону. Одежду и лицо не переноси из другого раздела.

### 3. Сгенерировать

1. Raster через image generation этого агента. Промпт: ограничения канона плюс один сюжет этого фрагмента.
2. В референсы клади только картинку настроения, если канон её назвал. Другие кадры не прикладывай.
3. Подпись, сетка, читаемый текст и тёплые цвета ставь только если их требует этот канон или этот запрос.
4. Соотношение: из запроса, иначе 16:9.
5. Путь: тот, что назвал пользователь. Просил новую папку: положи туда, не смешивай с чужими файлами.
6. Инструмент не сработал: скажи об этом. Другой медиум (сцена в 3D, HTML, SVG) не подставляй, пока об этом не попросили.

### 4. Проверить

Self-check. Стиль нарушен: один повтор генерации с тем же сюжетом и тем же каноном. Второй провал: остановись и скажи, что не совпало.

## Self-check

- [ ] Стиль прочитан из файла или текста этого запроса
- [ ] Сюжет взят из текущего фрагмента, не из соседнего кадра
- [ ] В референсах нет картинок, которые пользователь не задавал
- [ ] В кадре нет человека, одежды и предмета, которых нет в этом фрагменте и в этом каноне
- [ ] Файл лежит по пути из запроса
- [ ] Это не стиль DotCore; иначе работа ушла в `generate-dotcore-image`
