# Author Voice

Профиль голоса нужен не для копирования отдельных фраз, а для сохранения устойчивых
писательских решений автора: регистра, ритма, структуры, отношения к читателю и того,
что автор обычно не делает. Он отделяет стиль от темы, фактов и случайных ошибок.

Работай только с текстами самого пользователя или материалами, на использование которых
у него есть разрешение. Для чужого или живого автора предложи описать высокоуровневые
качества, а не создавать близкую имитацию.

## Где хранить профиль

По умолчанию создай или обнови `.author-voices/<author-id>.md` в текущем проекте.
`<author-id>` - короткий slug без персональных данных, например `me-ru-work`.

Если пользователь указал другое место, используй его. Не записывай профиль без явного
запроса создать или обновить его. Не копируй туда полный корпус, личные данные,
переписку или секреты: сохраняй только обобщённые наблюдения и краткий реестр источников.
Файл профиля перед записью и при каждом применении читай целиком.

Для формата профиля и процедуры обновления читай [profile-format.md](references/profile-format.md).

## Выбор операции

| Запрос | Действие |
|---|---|
| «сохрани / изучи мой стиль», дан корпус | Создай профиль |
| «добавь эти сообщения / статьи» | Обнови существующий профиль |
| «напиши / перепиши моим голосом» | Примени профиль, ничего не меняя в нём |
| «проверь, похоже ли это на меня» | Дай короткий разбор расхождений без правок |

Если операция не названа, но дан новый корпус без целевого текста, предложи создать
профиль. Если дан целевой текст и профиль, применяй профиль без сохранения новых данных.

## Создание профиля

1. Прочитай весь предоставленный корпус. Исключи цитаты, форварды, шаблоны, чужие
   фрагменты и тексты, которые автор сам считает нетипичными.
2. Раздели образцы по контекстам: например, личный чат, рабочее сообщение, статья,
   технический документ. Не смешивай их в один усреднённый голос.
3. Ищи повторяемость, а не эффектные единичные приёмы. Зафиксируй уверенность: высокая
   только когда признак подтверждён несколькими независимыми образцами.
4. Собери профиль по шаблону: подтверждённые черты, запреты, границы каждого контекста,
   несколько коротких оригинальных паттернов без дословного переноса больших фрагментов.
5. Проверь, что наблюдения описывают форму, а не тему. «Пишет о Python» - не стиль;
   «в техтексте начинает с вывода и не объясняет знакомые термины» - стиль.
6. Запиши версию и реестр источников. Верни путь к профилю и кратко назови контексты,
   для которых данных пока мало.

Не выдумывай манеру из трёх сообщений. При малом или однообразном корпусе создавай
черновой профиль с низкой уверенностью и проси 5-10 типичных примеров каждого нужного
контекста. Объём важнее счётчика: несколько содержательных писем полезнее десятков «ок».

## Обновление профиля

1. Прочитай текущий профиль и новые образцы.
2. Сравни новый корпус с существующими чертами. Подтверди их, уточни область действия
   или добавь новую черту только при повторяемом сигнале.
3. Не заменяй старый профиль внезапной темой, настроением или одним необычным текстом.
   Противоречие фиксируй как контекстную вариацию либо как наблюдение низкой уверенности.
4. Увеличь версию, дату и количество изученных образцов; добавь запись в журнал изменений.
   Не храни исходные сообщения, если пользователь прямо не попросил архив корпуса.

## Применение профиля

1. Прочитай весь профиль, целевой текст, задачу, адресата и требуемый формат.
2. Выбери только соответствующий контекст профиля. Для незнакомого жанра бери общие
   черты голоса, но не переноси привычки чата в статью или делового письма в личный диалог.
3. Сначала сохрани смысл, факты, цитаты, ссылки, имена и намерение. Затем меняй порядок,
   длину фраз, словарь, переходы и уровень прямоты по подтверждённым чертам профиля.
4. Не добавляй вымышленные личные воспоминания, позиции, шутки, факты, ошибки или сленг
   только ради «аутентичности». Не сглаживай реальную неровность, если профиль её допускает.
5. Проверь результат по списку «сохранять» и «избегать» в профиле. Убери случайные
   словечки, характерные лишь для примера, но не для автора в целом.

По умолчанию верни только готовый текст. Для режима проверки покажи 3-6 конкретных
совпадений или расхождений с профилем. Для новой версии профиля не выдавай весь корпус.

## Границы качества

- Стиль меняется по аудитории и жанру; соответствие контексту важнее усреднённого голоса.
- Профиль не доказывает авторство и не является средством обхода проверок происхождения
  текста. В учебных, юридических и иных регулируемых задачах соблюдай правила площадки
  и раскрывай использование ИИ, если это требуется.
- Если профиль конфликтует с ясностью, безопасностью, фактической точностью или форматом
  получателя, приоритет у этих ограничений.
