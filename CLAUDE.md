## Триггеры

- «Обнови README» / «сгенерируй README» → скилл `generate-readme`
- «Проверь перед деплоем» / «аудит безопасности» / «найди уязвимости» / «утечки» / «репо в public» → единый скилл `pre-deploy-audit`; полный запрос запускает coverage-led режим
- «Картинка в стиле dotcore» / «перерисуй в .ядро» / иллюстрация PNG/SVG → скилл `generate-dotcore-image`
- «Спроектируй интерфейс» / «сделай дизайн сайта или приложения» / «проверь UX/UI» → скилл `dotcore-design`
- «Убери ИИ-слог» / «humanize» / «de-AI» / «перепиши по-человечески» → скилл `sepia`
- «Сохрани мой стиль» / «пиши как я» / «добавь тексты к профилю» → скилл `author-voice`
- «Сделай текст живым» / «убери шаблонность» / «нормализуй текст» → скилл `text-naturalizer`
- «Сделай короткое видео о проекте» / «покажи приложение в ролике» / «product demo» → скилл `launch-video`
- «Сгенерируй HTML-анимацию» / «сделай плавный animated hero» / «анимация для видео» → скилл `html-motion`
- «Обнови AGENTS.md» / «синхронизируй правила проекта» → скилл `sync-project-rules`
- Глобальные изменения функционала (команды, модули, зависимости, архитектура) → обнови README + AGENTS.md теми же скиллами
- Правки документации → стандарт DotCore (см. AGENTS.md)
- Новый скилл → `skills/<name>/`, таблица README и ссылка в AGENTS.md; оба установщика находят папку автоматически
- Новый агент → `agents.targets.json` + `docs/AGENTS_PATHS.md`, проверь оба установщика

Не дублируй содержимое AGENTS.md здесь - обновляй AGENTS.md через скилл.
